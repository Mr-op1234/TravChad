# TravChad

Modern Travel Itinerary & Planning Application.

## Architecture

- **`web/`**: Next.js 15+ web application with interactive itinerary builder, rich text editor, drag-and-drop cards, document attachments, and dynamic responsive layouts.
- **`app/`**: Mobile application workspace.

## Getting Started

### Web Application

```bash
cd web
npm install
npm run dev
```

Runs the web client locally on http://localhost:3000 (or specified port).
